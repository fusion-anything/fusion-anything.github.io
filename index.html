From fixed fusion
to open settings.

Most multimodal models are trained around a predefined set of modalities and one prediction objective.

Existing paradigm

Image + Text → Model A

Audio + Video → Model B

Clinical image + patient metadata → Model C

New modality → retrain

The question

Can one model adapt to arbitrary modality combinations and arbitrary prediction tasks?

Synthetic data for
missing worlds.

Structural Multimodal Causal Models generate diverse correlation patterns when real-world multimodal data are scarce.

Root representation
A shared latent state provides the underlying information.

Shared nodes
Selected information travels across multiple modality nodes.

Private nodes
Modality-specific variation remains local.

One model, many
prediction tasks.

Fusion Anything extends context-based prediction from structured data to heterogeneous multimodal settings.

of the evidence.

Hierarchical multimodal attention models relationships at three levels instead of treating every token as an unordered sequence.

LevelWhat it modelsWhy it matters
Modality-level attentionDependencies among tokens within one modalityPreserves modality-specific representation
Cross-modality attentionInteractions among modalities in one sampleCaptures complementary and shared information
Sample-level attentionInformation across contextual samplesInfers the task-relevant correlation pattern
